What the glow tells you, and how the print turns

The print lands face down. The tier colour on its back already told you the rarity, so the hover has a different job: it hints at the finish, and at the variant if there is one, without showing either. Then you click and the print turns. Hover a print to see its glow, click a print in the flip row to run it (it loops after). Pick one in each row and copy your picks.

Hover glow, one per finish

Six face-down prints on a black ground. Put the pointer over one and the glow comes up behind it. Each glow is built from the finish it hides, so a collector learns to read them. Leave the cell and it fades.

2

Variant tells

Twelve pulls in a hundred carry a variant on top of the finish. These sit over the foil glow and change it, so you know something extra is coming before the print turns.

3

The flip

Click a print to run its flip. Each one ends with the finish catching light and a small wobble, then it loops. Five different finishes across the five, so you see the shaders at the same time.
